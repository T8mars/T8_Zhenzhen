# T8与贞贞v7操作说明

| 原按键 | 用法 |
|---|---|
| Enter / 方向 / F / D | 开始暂停 / 移动 / 跳跃 / 加速与火球 |
| S / ↑S / ↓S | 召唤或前跳 / 顶砖或火箭 / 站定与跟随 |
| ↑E / ↓E / 方向E / E | 撑台 / 龟壳反踢或蘑菇挑传 / 拍背助跑 / 面对面碰拳 |
| ↑R / ←R或→R | 原生火球变线 / 空中贴掌换线 |

| 新玩法 | 操作 |
|---|---|
| 扇过来，我踩！ | R短推近处同一只普通怪；S主动让贞贞落踩。 |
| 队友保龄球 | ↓R抱膝；T8贴到她背后，沿她朝向按方向＋E轻推。只打首怪，空滚、遇墙或坑就收势。 |
| 这次贞贞当班 | Q进入短指挥，方向控制她，F让她跳；再Q返回T8。D/S/E/R也会退出并执行原操作。 |
| 坑边拉一把 | 她在固定坑边站稳时↑Q伸手；T8下降贴近手，再新按↑Q抓住，保持Q并按↑爬回，松Q放手。 |
| 借扇躲猫猫 | 两人地面近身↓Q借扇；E露头，再近身E接回。扇在她手里时，T8早接会伸空手。 |
| 背靠背摆帅 | 自己形成背靠背，W短摆帅；T8走开只取消自己的姿势，S让她先走，T8可继续摆。 |
| 托一下，再抛搭子 | 地面近身方向＋Q托住；保持Q、按左右合法换向，松Q短抛。F/D/S可放下；落踩、撞砖仍需真实碰撞。 |
| 留座赶车 | 在原生移动平台上真实落脚后↓S留座；平台照原轨迹运行，S从当前脚点跳离。1-2原生升降台已验证。 |
| 牵手借刹车 | 她在真实地面↓W伸手；T8地面贴近再新按↓W抓住，保持W逐步刹车，松W保留余速，F可退出。 |
| 扇下挤一挤 | T8真正下降时↑W举扇，保持W短缓降；她从上方真实落背后两人下降更快，S让她离背；不增加向上速度。 |

先按住方向，再新按技能键。托举与抓边要保持Q，刹车与缓降要保持W。短指挥是主动切换：F此时给贞贞，退出后恢复T8。抓手、托举、背载不会刷新借头或空中接力次数。保龄球准备由贞贞持有，T8普通走跳不会取消；旧S立即让她执行原动作。

三张挑战卡：**一球一补位**（她滚首怪，T8处理下一只，再会合）；**接到再庆祝**（她顶蘑菇→↓E挑传→T8接住→一起长大→碰拳）；**一人拆一处**（她供借头，T8顶砖，落地交换支撑人，再由她顶另一块）。这些是玩家的玩法约定，无常驻计分条；目标消耗后用原游戏重新开局重试，不复制敌人或道具。
